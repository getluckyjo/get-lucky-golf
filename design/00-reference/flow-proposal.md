# Flow proposal

**Fill this in only if you want to change how the screens are composed.** If today's screen
map is right, leave this file alone and mark every card `REDESIGNED`.

This is a **Stage 0 deliverable** — it comes with the concept directions, before anything is
resolved. The reason is cost. Changing what a screen looks like is a day of engineering.
Changing how many steps sit between "choose a stake" and "money has moved" touches payment
state, verification and the bet record. A proposal gets a yes, a no, or a counter within a
day. A surprise in wave three does not.

Nothing here is binding on you until it comes back agreed.
